This directory contains all the relevant code for the MyoGym-based CNN-ResBiGRU exercise classification model used by Team 1A in the Wearable Health Technologies course at Carnegie Mellon University. The notebooks and data paths are setup for a Google Colab workflow. Below are the papers the model was used from.

Paper for dataset: https://www.researchgate.net/publication/319603676_MyoGym_introducing_an_open_gym_data_set_for_activity_recognition_collected_using_myo_armband </br>
Paper using the dataset to train CNN-ResBiGRU model: https://www.mdpi.com/2571-5577/7/4/59</br>
GitHub: https://github.com/lok63/HAR-for-fitness-data/tree/master</br>
